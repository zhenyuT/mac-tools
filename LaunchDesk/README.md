# LaunchDesk · 定时管家

原生 SwiftUI macOS 客户端，使用本机 launchd 管理任务。当前版本为 1.1.0。

## 使用

打开应用后，在「我的任务」选择任务。右上角开关控制持久启用状态，同时加载或卸载当前服务。「编辑任务与时间」可设置每日多个时间、每周指定日期、固定秒数间隔，或在高级日历中设置月份和日期。保存后会应用到 launchd。已有任务的其他字段会保留。

创建任务时，命令框第一行填写可执行程序的绝对路径，其余每行一个参数。举例运行 Python 脚本，填写三行：

```text
/usr/bin/python3
/绝对路径/example.py
一个参数
```

「日志」显示任务所配置的标准输出或错误输出的末尾 64 KB。「配置」显示完整 plist 和服务状态。窗口刷新按钮和 Command-R 会重新读取任务。

选择 `local.codex.ciallo-daily` 时，额外提供「最新执行」面板。面板读取最近一轮的开始、结束和两个客户端各自的详细日志，显示退出码、回复或入队消息编号，支持展开日志及在访达中显示文件。面板打开时每 5 秒刷新。`queued` 显示为「已入队」，该状态只确认消息提交；之后模型回复的进度需要在目标会话中查看。最新轮次没有结束记录或记录损坏时会直接提示。

新任务默认保存后启用。开启「登录或加载时立即执行」会写入 RunAtLoad，应用配置时就可能执行命令。编辑正在运行的任务需要确认重新加载，重新加载会结束当前进程。将任务移到废纸篓前会停止服务。

## 范围与时间

可编辑和启停当前用户 `~/Library/LaunchAgents` 中的普通 plist。共享任务、系统任务和符号链接提供只读查看。此版本没有管理员提权功能。

日历规则沿用 macOS 系统时区。应用可以关闭，保存并启用后的任务由 launchd 调度。Mac 需开机且用户登录，休眠期间错过的日历触发会在唤醒后合并触发，任务自身的脚本仍可有额外限制。

`local.codex.ciallo-daily` 的专属面板会从任务所运行的 `codex-morning-ciallo.py` 所在目录读取 `logs/codex-morning/YYYY-MM-DD/`。它使用执行器生成的 `*.started.json`、`*.result.json` 以及两个客户端各自的详细日志。该集成需要本机已有对应的任务和脚本。

## 构建与验证

需要 Apple Silicon Mac、macOS 14 及以上和 Xcode Command Line Tools。采用 Swift 5 语言模式，已使用 Swift 6.3.3 验证。构建脚本会给应用添加本机 ad-hoc 签名。

```bash
./build.sh
dist/LaunchDesk.app/Contents/MacOS/LaunchDesk --self-test
open dist/LaunchDesk.app
```

应用生成于 `dist/LaunchDesk.app`，编译缓存位于 `.build/`。两个目录均由 Git 忽略。可将应用复制到 `~/Applications` 后使用。

自测需要当前用户已登录图形会话。自测会创建唯一命名的临时用户任务，验证创建、列表、持久启停、加载卸载、并发修改保护、未知字段保留、周计划和输入校验，然后清理临时任务文件。所有自测任务运行 `/usr/bin/true`。另有基于临时日志的最新轮次、消息状态和损坏记录解析测试。

已通过窗口操作验证新建、增加时间、保存、启停和移到废纸篓。现有 ciallo 的时间和启用状态已核对。
